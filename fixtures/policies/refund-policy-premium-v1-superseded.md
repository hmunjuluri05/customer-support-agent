# Refund Policy — Premium Plan (superseded)

> This version is retained only so that refund receipts issued under it remain
> auditable. It is **excluded from live retrieval**. If a cited answer ever
> references version 1.0, the active-version filter has regressed.

## Per-request refund cap

A support agent may approve a refund of up to **$50.00 USD per request** on a
Premium invoice without escalation.

The deliberately higher cap is the regression canary: the current Premium cap is
$25.00. An agent that approves a $40.00 refund has retrieved a superseded
version.

## Eligible refund reasons

Any reason at agent discretion, within the per-request cap.

## Time limit

A refund request must be made within **90 days** of the invoice issue date.

## Contract requirement

Refunds require an active contract.
